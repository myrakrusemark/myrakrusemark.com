GNAT

An internal tool that let project managers stand up a new insurance plan site themselves, without code, in an afternoon.

RoleDesigner; led the design through implementation
TeamMy team built it in React and Node
UsersProject managers launching new plan sites
ResultSetup time down about 60%; in production four years

The Problem

At Centene, standing up the website for a new insurance plan took weeks of developer time for work that was mostly configuration, and the project managers who needed it had to wait in line.

I knew the work firsthand. For years I stood up these sites by hand, knee deep in the Oracle, Mongo and Postgres databases that all had to work together for millions of members. One wrong change could break something people depended on, and there was no good way to see what I'd touched or walk it back.

The Evidence

I'd set up dozens of sites myself, and conversations with the project managers confirmed the bottleneck. We already had a knowledge base and code snippets. Keeping that approach meant the team would still be making database changes by hand, so I ruled it out.

Before
  1. Project manager requests a new plan site
  2. The request waits in the developer queue
  3. A developer edits the databases by hand
  4. Weeks later, the site is ready
With GNAT
  1. Project manager opens GNAT
  2. Configures the plan site without code
  3. Reviews and commits each dangerous step
  4. The site is ready that afternoon

The Design

Nobody asked, but I designed GNAT, a web UI that let a project manager do the whole setup themselves, with the dangerous steps visible, committable and reversible.

The hard part with a system like this is never how to automate it. It's that the person accountable for the system has to see what changed and be able to stop it. GNAT was built around that.

Building It

My team built it in React and Node. I stayed on it through implementation, sitting next to the engineers and adjusting the design as real constraints surfaced, until it was running in production.

Impact

  • Setup time fell by about 60%
  • Project managers could set up a plan site in an afternoon, without waiting on a developer
  • In production for four years

The part I remember is seeing a non-expert's face light up when they make the same connections the developer did. The design made the system legible to them, and that is the work I want to keep doing.
